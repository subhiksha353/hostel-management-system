1. Executive Summary & Core Mission

CampusVoice & HostelConnect is an integrated digital governance and residential operations platform engineered to solve campus administrative bottlenecks through four core pillars:

  • Zero-Knowledge Grievance Redressal: Enables students to voice complaints without fear of academic or hostel reprisal by cryptographically stripping personal identifiable information (PII).
  • Digital Outpass & Leave Automation: Eliminates paper logbooks with a complete digital leave application, parent consent validation, dynamic warden approvals, and QR-encoded gate passes.
  • Mess Attendance & Food Waste Minimization: Provides real-time resident headcount tracking across Breakfast, Lunch, Snacks, and Dinner to prevent excessive meal preparation.
  • Campus Emergency Red Channel (108 SOS): Bypasses standard review queues for immediate life safety hazards, linking directly to national emergency 108 and campus leadership.

5. Database Schema & Data Models

A. Collection: complaints

Field Type Constraint Description
id String Primary Key Unique document identifier (e.g. c-1726000000000).
public_tracking_id String Unique, Immutable Public reference code (e.g. CV-9821A) for anonymous lookup.
anonymous_public_id String Immutable Masked pseudonym (e.g. Anonymous Student #842).
category String Required Hostel, Water, Mess/Food, Electricity, Classroom, Lab, Infrastructure.
priority String Enum low | medium | high | critical.
status String Enum submitted, acknowledged, in_progress, resolved, rejected.
is_emergency Boolean Required True if submitted via Red SOS emergency channel.
upvote_count Number Integer >= 0 Community upvote counter.
messages Array<Map> Optional Threaded anonymous follow-up messages between student and staff.

B. Collection: leave_requests (SpaceBasic Outpass)

Field Type Description
student_id / student_name String Resident student identifying credentials.
room_number / hostel_block String Specific room and residential block location.
leave_type String day_pass, weekend_home, night_out, emergency.
from_date / to_date String Outpass travel dates and return curfew times.
parent_phone String Parent/guardian verification phone number.
status String pending, approved, rejected, checked_out, checked_in.
qr_pass_code String Encrypted string (e.g. SB-PASS-204-9812) verified by watchman camera.
approved_by / warden_remarks String Warden verification credentials and curfew conditions.

6. Role-Based Access Control (RBAC) & Portals

1. 🎓 Student Anonymous Portal (/student/dashboard): Submit grievances with zero PII, track ticket progress via public token, apply for outpasses, and manage daily meal attendance.

2. 📋 Hostel Warden Portal (/management/dashboard): Real-time queue of block grievances, SpaceBasic outpass approvals with one-click approve/reject, and student curfew monitoring.

3. 🚪 Gate Security / Watchman Portal (/watchman/scan): Uses the mobile/desktop web camera to scan QR barcodes on student outpasses and verify legitimacy instantly.

4. 🍽️ Mess Chef & Kitchen Dashboard (/chef/dashboard): Live daily headcount counter (Breakfast, Lunch, Snacks, Dinner), raw material requirement forecasting, and food waste reduction analysis.

5. 🏢 College Management Portal (/college-management/dashboard): Academic building grievances, classroom projector and AC tickets, computer laboratory faults, and direct anonymous feedback to principal/director.

6. 🔐 Admin Control Room (/admin): Complete platform oversight, live logo/name re-branding customizer, purge fake/spam tickets, and Cloud Firestore sync manager.
